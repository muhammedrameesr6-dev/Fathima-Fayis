## Project Structure

- `index.html` — Main invitation page with interactive elements (splash screen, hero, reception details, countdown timer, venue map, couple photo, wishing box, audio player)
- `style.css` — Custom styling (luxury dark crimson / maroon / gold theme, animations, responsive design)
- `script.js` — Client-side scripts (falling flower petals, live countdown to Dec 27 2026 6:00 PM, splash screen dismissal, music controls, WhatsApp wishing box)
- `music.mp3` — Background instrumental audio
- `couples.jpg` — Couple photograph
- `rashid.png` — Hero section background artwork
- `og.jpg` — Open Graph preview thumbnail

## Running Locally

You can preview the site using any static web server:

```bash
# Python 3
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your web browser.

Alternatively, you can open `index.html` directly in any modern browser.
